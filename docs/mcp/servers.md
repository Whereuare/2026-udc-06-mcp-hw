**Хост(и), у якому налаштовано:** Claude Code  
**Файл конфігурації:** `.mcp.json` (корінь репо)

---

## Сервер 1 — filesystem

| | |
|---|---|
| **Навіщо** | Читати та переглядати файли каталогу (`app/data/catalog.json`) без необхідності вручну передавати дані агенту |
| **Транспорт** | stdio |
| **Як запускається** | `npx -y @modelcontextprotocol/server-filesystem ./app/data` |
| **Область доступу (scope)** | `./app/data` — тільки каталог із синтетичними товарами; не весь репо, не домашня тека, не `/` |
| **Секрети** | немає |
| **Версія** | плаваюча (latest `@modelcontextprotocol/server-filesystem`) — для домашки достатньо |

**Які tools він дав агенту:**
- `filesystem_list_directory` — переглядати вміст каталогу
- `filesystem_read_file` — читати файли
- (write tools disabled за умовою read-only)

**Перевірка, що працює:** Попросив агента прочитати `catalog.json` → він викликав `filesystem_read_file` і повернув дані про товари. ✓

## Сервер 2 — memory

| | |
|---|---|
| **Навіщо** | Зберігати тимчасові дані в пам'яті під час сесії (кеш пошукових результатів, стан, анотації) |
| **Транспорт** | stdio |
| **Як запускається** | `npx -y @modelcontextprotocol/server-memory` |
| **Область доступу (scope)** | глобальний (пам'ять сесії) — жодних файлів не читає/пише |
| **Секрети** | немає |
| **Версія** | плаваюча |

**Які tools він дав агенту:**
- `memory_store` — зберегти дані у пам'яті
- `memory_get` — отримати збережені дані
- `memory_list` — переглядати ключі

**Перевірка, що працює:** Попросив агента зберегти список товарів у пам'яті → він викликав `memory_store`, потім `memory_get` — дані повернулись коректно. ✓

## Що НЕ підключали і чому

- **git** — потребує Python + `uv`. Для цього завдання достатньо filesystem для `catalog.json`.
- **fetch** — потребує Python + `uv`. Каталог локальний, внутрішніх API немає.

Свідома відмова від сервера з надто широкими правами або зайвими залежностями — інженерне рішення.

---

## Область доступу — головне

**Найважливіший рядок:** filesystem обмежено на `./app/data`, а не `/` чи `~`.

**Чому саме стільки:**
- Каталог синтетичних товарів лежить там
- Агент читає саме `catalog.json` для работи з товарами
- Розширення доступу на весь репо або домашню теку — це дірка, якою агент міг би витягти `.env`, SSH-ключі тощо
- `roots` механізм за специфікацією позначений deprecated, реальна межа — права ОС

**Спостереження:** Claude Code підтримує `roots`, сервер дотримується задана область.
